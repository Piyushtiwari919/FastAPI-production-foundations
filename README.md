# FastAPI Production Foundations

A hands-on repository where I am learning FastAPI by translating
backend concepts from Node.js/Express into production-oriented Python.

## What I'm practicing

- FastAPI routing
- ASGI and Uvicorn
- Pydantic validation
- Dependency Injection
- Lifespan management
- Middleware
- Request tracing
- Async/await
- Background tasks
- Modular API architecture
- Service-layer design

## Why I'm building this

I'm coming from a Node.js/Express background and am using
FastAPI to understand how production Python backends are designed,
validated, and served.
